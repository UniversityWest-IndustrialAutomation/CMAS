CMAS Command Line Arguments

Command Line

CMAS supports command line options in the form of key/value pairs, with an optional project file name as the last parameter.
If a file name is specified, that project file will be automatically loaded after CMAS starts. The file name can also be specified as a key/value pair (e.g., file=project.cmas).

Key/value pairs can be specified either as:

  • parameter=value (e.g., debug=true)
  • parameter value (e.g., debug true)

Boolean options accept any of the following forms:
true / false, t / f, or 1 / 0.

Preferences and Command-Line Overrides

All settings in CMAS are by default loaded from the preferences file
cmas-preferences.json when the application starts.

Each command-line option can override the corresponding value from the preferences for that session.
The only exception is the loadpreferences option, which controls whether the preferences file is loaded at all.

When CMAS is closed, all current preference values — including those changed via command-line arguments or through the user interface —
are saved back to the cmas-preferences.json file.

Note: If you start CMAS with debug=true, that value will be saved to the preferences.
The next time CMAS starts, debug mode will remain enabled by default unless you explicitly set debug=false.

General Options

Option Default Description Example
loadpreferences true Loads application preferences from cmas-preferences.json. If set to false, CMAS will start with default preferences. cmas loadpreferences=false
file true Loads a CMAS project after start. cmas file=project.cmas

LibrarySave true When saving a project, also save any changes to libraries. cmas LibrarySave=false
ConsoleMirror false Mirror console output (requires restart to take effect). cmas ConsoleMirror=true

Developer Modes

Option Default Description Example
debug false Enables or disables debug mode. When set to true, the Debug property in preferences is enabled. cmas debug=true
mirror false Enables console and log mirroring by setting the ConsoleMirror and LogMirror preferences to true. cmas mirror

Example Usage

This example starts CMAS in debug mode, disables the modern title bar,
and automatically loads the project file project.cmas after startup.

cmas debug=true titlebar=false project.cmas
