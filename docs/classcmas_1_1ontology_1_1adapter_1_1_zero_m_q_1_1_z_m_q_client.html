Detailed Description

ZeroMQ communications for variables

   For adapter type of ZeroMQ the specific format is: ZMQ.type:[TCP]:[//host]:[port]
   eg, ZMQ:tcp://*:5555

Type can one of: DEALER, PAIR, PUB, PULL, PUSH, REP, REQ, ROUTER, STREAM, SUB, XPUB, XSUB
