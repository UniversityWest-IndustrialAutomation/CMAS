Processplan action

A process plan will be executed according to the folloing steps;

State name Description
Init Constructor is called
Negotiate onNegotiate is called
Running onRun is called
Finished onFinished is called

The function onRun() is a user-defined function that must always exists. The function must be of type integer and the return values from the function must be one of the following;

Integer value Predefined constant Explanation
1 processplan.running Still running, the onRun() function will be called again at the next cycle
2 processplan.done Ongoing activities are done
3 processplan.failed Indicates a failure and ongoing running will be aborted
4 processplan.interrupted Indicates an interruption


Note
It is not a good approach to block the onRun() function with an extensive loop or to wait for a specific value. This will generate a time out in the system an the process plan will be aborted. This can be turned off in preferences by setting timeout to 0 (use it for debug purposes only).


Note
onNegotiate is only called if another agent ask for a negotiation. It is possible to return false to state that the process plan is not compatible or true to accept.



In the following example a process plan is created to make two holes. It also demonstrate how to make loop where each iteration must return back the control to the system to avoid time out.


Program Processplan;
abstract aResource : interface;
var steps: integer;
function onNegotiate() : boolean;
begin
if remoteinterface.diameter=5.0 then
onNegotiate:=true;
else
onNegotiate:=false;
end.
function onRun() : integer;
begin
if steps=0 then
begin
aResource.x:=10.0;
aResource.MakeAHole();
onRun:=processplan.running;
end;
else if steps=1 then
begin
aResource.x:=20.0;
aResource.MakeAHole();
onRun:=processplan.running;
end;
else
onRun:=processplan.done;
steps:=steps+1;
end.
// Constructor
begin
steps:=0;
end.
