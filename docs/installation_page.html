Installation of CMAS

Download

The latest version of CMAS is available from the CMAS GitHub repository.

Download the latest release and extract the ZIP archive to a local directory where you have permission to execute applications.

Requirements

CMAS is a self-contained application built with Java and JavaFX. The distribution includes the Java runtime, JavaFX, CMAS, and all runtime components required to run the application.

No separate Java or JavaFX installation is required.

The current version supports the following platforms:

  • Windows
  • macOS on Intel and Apple Silicon
  • Linux on x86-64

Starting CMAS

Start CMAS using the appropriate launcher for your operating system:

  • Windows: Run CMAS.exe.
  • macOS and Linux: Run CMAS.sh.

CMAS can be started directly from the extracted directory. No additional installation steps are normally required.

Troubleshooting

Windows

If Windows displays a security warning, verify that CMAS was downloaded from the official GitHub repository before allowing the application to run.

Make sure that the ZIP archive has been extracted before starting CMAS.exe.

macOS and Linux

If CMAS.sh cannot be executed, open a terminal in the extracted CMAS directory and grant the script execution permission:

chmod +x CMAS.sh

Then start CMAS using:

./CMAS.sh

macOS may block applications downloaded from the internet. If this happens, verify the download source and review the operating system's security settings.

General troubleshooting

If CMAS does not start, check the following:

  • The ZIP archive has been fully extracted.
  • The original directory structure has been preserved.
  • The application has appropriate permissions.
  • The operating system has not blocked the application.

If the problem persists, launch CMAS from a terminal or command prompt to inspect any error messages displayed during startup.
