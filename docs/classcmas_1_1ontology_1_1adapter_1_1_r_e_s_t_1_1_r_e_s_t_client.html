Detailed Description

Main class for REST communication using POST and GET

Ideas from: https://stackoverflow.com/questions/32586626/java-equivalent-of-networkcredential Examples in ABB Robot Web Services: https://developercenter.robotstudio.com/api/rwsApi/_hello_controller_json_8cs-example.html 

       For adapter type of REST the specific format is: REST:[HTTP]:[HOST]:[PORT]:[AUTH]:[USER]:[PASW]
       eg, REST:http:localhost:80:/rw/rapid/symbol/data/RAPID/T_ROB1/MainModule/:DIGEST:Default User:robotics
       opc.tcp is static for OPC UA
       HTTP http or https
       HOST is the host name or TCP/IP address to the server
       PORT is the port number to the server
       AUTH  is the name of the authentication type to use it can be DIGEST, BASIC or NONE
       USER User name
       PASW Password
